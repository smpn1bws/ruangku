# ruangku ( Ruang Untuk Akses Navigasi Guru, Kelas, dan Unit )
* Sistem peminjaman unit PID berbasis web yang dapat digunakan untuk melakukan pengajuan peminjaman dan pengelolaan unit. Dibuat sebagai alternatif dari mekanisme peminjaman unit secara manual yang umumnya menggunakan media kertas untuk melakukan pengajuan peminjaman.
* * Sistem peminjaman ruangan berbasis web yang dapat digunakan untuk melakukan pengajuan peminjaman dan pengelolaan ruangan. Dibuat sebagai alternatif dari mekanisme peminjaman ruangan secara manual yang umumnya menggunakan media kertas untuk melakukan pengajuan peminjaman.
* Digunakan untuk mendata dan memanfaatkan fasilitas sekolah demi kelancaran proses mengajar.
* Memenuhi kebutuhan guru yang sering memerlukan ruangan kelas tambahan dan atau Unit PID secara cepat.
