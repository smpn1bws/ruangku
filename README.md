# ruangku ( Ruang Untuk Akses Nyaman Guru, Kelas, dan Unit laboratorium )
Sistem peminjaman ruangan PID berbasis web yang dapat digunakan untuk melakukan pengajuan peminjaman ruangan dan pengelolaan peminjaman ruangan. Dibuat sebagai alternatif dari mekanisme peminjaman ruangan secara manual yang umumnya menggunakan media kertas untuk melakukan pengajuan peminjaman.
Digunakan untuk mendata dan memanfaatkan fasilitas sekolah demi kelancaran proses mengajar.
Memenuhi kebutuhan guru yang sering memerlukan ruang kelas tambahan secara cepat.
